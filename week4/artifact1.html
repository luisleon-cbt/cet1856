How the exam asks this

Domain 6 questions follow four reliable patterns.

Pattern 1: the planes and the APIs

Data plane forwards packets. Control plane decides where they go (routing protocols, STP). Management plane is how humans and tools configure the device (SSH, SNMP). A controller centralizes the control plane. It talks northbound to apps (usually REST) and southbound to devices (NETCONF, RESTCONF, OpenFlow).

Trap: north vs south reversed. Northbound faces the applications above; southbound faces the devices below.

Pattern 2: REST verbs and status codes

GET read, POST create, PUT/PATCH update, DELETE delete. REST is stateless: each request carries everything needed, including authentication (often a token header). Status codes: 200 OK, 201 Created, 204 No Content, 401 Unauthorized, 403 Forbidden, 404 Not Found, 500 server error.

Trap: POST vs PUT. POST creates a new resource; PUT replaces or updates an existing one.

Pattern 3: reading JSON

Curly braces { } hold an object of key/value pairs. Square brackets [ ] hold an array (an ordered list). Keys are always quoted strings. Values can be strings, numbers, true/false, null, objects, or arrays. Count array items by counting the objects between the brackets.

Trap: "10" in quotes is a string, 10 without quotes is a number. The exam tests the difference.

Pattern 4: tools, and AI in operations

Ansible: agentless, push, YAML, SSH. Puppet and Chef: agent-based, pull. Terraform: declarative infrastructure as code. For AI: predictive AI forecasts from historical data (capacity, failures), generative AI produces new content (configs, summaries, chat assistants), and machine learning is how both learn patterns from data.

Trap: "detect anomalies and forecast a link failure before it happens" is predictive, not generative.
