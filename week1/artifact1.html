How the exam asks this

Services questions follow four reliable patterns. Learn the pattern, bank the points.

Pattern 1: the DORA sequence, with the broadcast detail

Order: Discover → Offer → Request → Acknowledge. Discover and Request come from the client (broadcast, because it has no usable address yet); Offer and Acknowledge come from the server. Ports: UDP 67 server, UDP 68 client.

Trap: "DORA" answers scrambled to DRAO or DOAR are always among the options. Say the acronym before you look.

Pattern 2: the relay question

DHCP Discover is a broadcast, and routers do not forward broadcasts. The moment a scenario puts the client and the DHCP server on different networks, the answer is ip helper-address on the router interface facing the clients: it converts the broadcast to unicast aimed at the server.

Trap: the helper address goes on the interface closest to the CLIENTS, not the server.

Pattern 3: syslog severity logic

0 to 7, lower is worse: Emergency, Alert, Critical, Error, Warning, Notification, Informational, Debugging. Configuring a trap level sends that level and everything more severe: level 4 sends 0 through 4.

Trap: "which levels are sent at logging trap 3?" means 0, 1, 2, AND 3, never just 3.

Pattern 4: NTP stratum and why time matters

Stratum counts hops from the reference clock: lower stratum = more authoritative. A device syncing from a stratum 2 server becomes stratum 3. The "why" answer: accurate time makes syslog timestamps and certificates trustworthy: without it, you cannot correlate events across devices.

Trap: stratum 0 is the clock itself (GPS, atomic); it is not a server you point ntp server at.
